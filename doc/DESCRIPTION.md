Rowflare is an open-source, Airtable-style database. Each base is stored as its own SQLite database, and the app runs the same Worker code as the Cloudflare version, in workerd (Cloudflare's open-source Workers runtime).

### Features

- Grid, kanban, calendar, timeline, gallery and form views, with filters, sorts, grouping and per-group summaries
- 20 field types, including links between tables, lookups, rollups and formulas in the Airtable formula language
- Real-time collaboration, undo and redo
- Import from CSV or directly from Airtable (tables, links, formulas and attachments)
- Public forms with a shareable link
- REST API modeled on the Airtable Web API, and an MCP server for AI clients
- Dashboards, automations (record triggers, schedules, webhooks, HTTP and email steps) and AI fields with your own API key
- Workspaces with owner, editor and viewer roles
